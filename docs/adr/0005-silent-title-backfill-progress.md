# 5. 제목 백필의 진행 팝업 생략

Date: 2026-11-23

Status: Accepted

## Context

기존 색인에 제목 벡터를 채우면 노트 수만큼 대기 줄이 늘어난다. 제목 한 줄씩
빠르게 처리할 때, 기존 100개 단위 진행 팝업이 연달아 쌓인다. 상태줄은 같은
대기 수를 이미 보여 준다.

## Decision

제목 백필은 상태줄 총 대기 수에는 포함하고 진행 팝업 계산에서만 제외한다.
백필과 일반 색인이 섞이면 일반 변경의 대기 수로 기존 임계값을 계산한다.
규범 동작은 [제목 벡터 명세](../title-vector-spec.md#backfill)에 둔다.

## Alternatives considered

- 시작할 때 한 번 제목 색인 안내: 반복 팝업은 줄지만, 이미 상태줄에 있는
  진행 정보 외에 새 문구와 알림 수명 관리가 필요해 채택하지 않았다.
- 모든 색인 진행 팝업 제거: 시간이 긴 일반 본문 색인의 기존 피드백까지
  바꾸므로 범위를 넓히지 않았다.
- 시간 간격으로 팝업 제한: 제목 백필만의 문제를 해결하려고 일반 색인의
  알림 주기까지 바꾸고 시간 상태를 추가하게 되어 채택하지 않았다.

## Consequences

제목 백필은 상태줄을 통해 조용히 진행된다. 일반 색인 진행 알림과 오류
알림은 유지한다. 사용자 설정과 저장 형식은 바꾸지 않는다.
